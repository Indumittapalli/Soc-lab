# 📸 SOC Lab Evidence

This directory contains evidence collected from the SOC Home Lab during
security monitoring, detection, and investigation activities.

The evidence demonstrates practical analysis of:

- Windows Event Logs
- Sysmon telemetry
- Authentication activity
- PowerShell execution
- DNS activity
- Network scanning
- Malware-related activity
- Phishing indicators
- IOC investigation
- Incident timelines

## Evidence Categories

| Category | Evidence |
|---|---|
| 🔐 Brute Force | Authentication failures and successful login correlation |
| ⚡ PowerShell | Suspicious PowerShell execution and process activity |
| 🌐 DNS | Suspicious domain/query investigation |
| 🔎 Port Scanning | Network reconnaissance activity |
| 🦠 Malware | Suspicious process and file activity |
| 🎣 Phishing | Email, URL, domain and IOC analysis |

## Evidence Handling

All evidence in this project is generated or collected from a controlled
educational lab environment.

Sensitive information such as real credentials, private IP addresses,
personal information, and production data should not be included.

## Investigation Evidence

Each investigation should document:

1. Alert observed
2. Timestamp
3. Source host
4. Source IP
5. Destination
6. Relevant log/event
7. IOC identified
8. Analyst observations
9. MITRE ATT&CK mapping
10. Final disposition
